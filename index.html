A reason behind it.

LoanWise AI is an academic decision-support prototype demonstrating machine learning and Explainable AI. The included synthetic dataset currently trains the model on applicant income, co-applicant income, loan amount, loan term, credit history, education, self-employment and property area. Additional history fields are displayed for the application demonstration but are not model inputs yet.
